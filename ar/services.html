الشبكات والكاميرات

شبكات سلكية ولاسلكية ثابتة، وكاميرات مراقبة تتابعها من موبايلك.

  • تمديد وتجهيز الشبكاتتمديد كابلات منظم وسويتشات وراوترات للمكاتب الصغيرة والمتوسعة.
  • نقاط الشبكةتركيب نقاط شبكة جديدة واختبارها في المكان اللي تحتاجه.
  • إعداد الراوتر والسويتشإعداد نظيف وآمن لإنترنت ثابت في كل المكتب.
  • إعداد وتقوية وتأمين الواي فايتغطية أحسن وكلمات سر قوية وشبكة منفصلة للضيوف.
  • تركيب كاميرات المراقبةتركيب كاميرات داخلية وخارجية في الأماكن الصح.
  • إعداد DVR / NVR والمشاهدة بالموبايلإعداد التسجيل وربطه بالتطبيق على موبايلك.
  • نقل شبكة المكتببتنقل لمكتب جديد؟ بننقل الشبكة ونجهزها بأقل وقت توقف.

السيرفرات

سيرفرات متجهزة صح، عليها باك أب، وشغالة على طول.

  • تنصيب Windows Serverتنصيب وإعداد Windows Server بشكل نظيف.
  • Active Directory والدومينإدارة مركزية للمستخدمين وتسجيل الدخول والتحكم في كل الأجهزة.
  • DNS / DHCP / GPOإعداد خدمات الشبكة الأساسية والسياسات بشكل صحيح.
  • File Server والمجلدات المشتركةمجلدات مشتركة بصلاحيات مناسبة لكل فريق.
  • إصلاح أعطال السيرفراتبنشخص مشاكل السيرفر ونحلها بسرعة.
  • أنظمة الباك أبنسخ احتياطي تلقائي عشان بياناتك ما تضيعش.
  • استرجاع البياناتاسترجاع البيانات المفقودة من وسائط التخزين التالفة.
  • تركيب وتنظيم الراكراك منظم ومتعلّم وسهل في الصيانة.
